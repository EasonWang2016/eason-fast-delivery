# Eason Fast Delivery Food

Eason Fast Delivery Food is a Fabric mod that adds boiled eggs and a faster delivery phone that calls Delivery Steve.

## Features

- Adds boiled eggs as a food item.
- Adds a delivery phone for faster food delivery.
- Adds money used by the delivery system.
- Includes English and Simplified Chinese translations.

## Requirements

- Minecraft 26.3
- Fabric Loader 0.19.5 or later
- Java 25 or later

## Installation

1. Install Fabric Loader for Minecraft 26.3.
2. Download `eason-delivery-fast-mod-1.0.7.jar`.
3. Place the JAR file in your Minecraft `mods` folder.
4. Start Minecraft with the Fabric profile.
